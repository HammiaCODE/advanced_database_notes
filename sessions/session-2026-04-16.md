## What I understood
- It's a structure that creates an index which allows the user to retrieve data quickly instead of having to look up for the information through the entire table. 

Types of index:
    - B tree
    - Object index
    - Hash, faster but occupies more space
    - Composite index - status, description
    - Partial index - only applied to a part of the table
