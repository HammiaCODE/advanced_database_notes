## What I understood
- SQL COMMIT, for permanent saves
- SQL SAVE POINT, for partial rollback
- SQL ROLLBACK, to revert to a certain state or save point

```sql
COMMIT; 
ROLLBACK; 
-- ALT
SAVEPOINT [name of savepoint];
ROLLBACK TO SAVEPOINT [name of savepoint];
```
